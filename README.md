# 放映清单

一个部署在 GitHub Pages 上的私人待看电影墙。

网站数据位于 `site/data/movies.json`。每次更新 `main` 分支后，GitHub Actions 会自动发布最新版本。

## 当前片单

- 蜘蛛侠：崭新之日
- 年会不能停！2
- 给阿嬷的情书

## 数据说明

电影资料来自 TMDB、豆瓣等公开资料源。TMDB API 密钥不会进入前端代码或仓库。

每条电影数据同时记录加入时间、已看时间、主演、豆瓣评分及评分更新时间。当前豆瓣评分通过公开电影页面查询，不需要 API Key；新增或更新电影时应重新查询并写入最新评分。网页中的“已看”状态保存在浏览器本地，不会修改仓库数据。
